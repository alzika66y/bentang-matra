# Bentang Matra
Versi 1.0 - Sistem Komando Intelijen Alam Bebas

### Deskripsi
Proyek ini adalah sistem digital yang dikembangkan untuk mendukung manajemen logistik dan pusat komando taktis. Fokus utama dari proyek ini adalah efisiensi navigasi dan operasional di lapangan.

### Fitur Utama
- Manajemen data logistik.
- Pemetaan dan navigasi taktis.
- Integrasi sistem untuk efisiensi operasional.

### Teknologi
- HTML5, CSS3, JavaScript, dan leaflet JS.
